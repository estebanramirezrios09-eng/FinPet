# FinPet 🐾

FinPet es un MVP académico desarrollado para el proyecto de aula de Ingeniería de Software.

## Descripción

FinPet busca ayudar a jóvenes y adultos jóvenes a llevar un registro sencillo de sus ingresos y gastos personales. La propuesta incorpora una mascota virtual que brinda retroalimentación contextual para motivar al usuario a mantener el hábito de registrar sus movimientos financieros.

## Funcionalidades del MVP

- Registro de ingresos.
- Registro de gastos.
- Clasificación por categorías.
- Consulta de movimientos.
- Cálculo de ingresos, gastos y saldo.
- Resumen de gastos por categoría.
- Comparación de gastos entre meses.
- Mascota virtual con mensajes de retroalimentación.
- Almacenamiento local de los movimientos mediante `localStorage`.

## Tecnologías

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir `index.html` en un navegador.
3. Registrar ingresos y gastos desde el formulario.
4. Consultar el resumen financiero y la retroalimentación de FinPet.

No requiere servidor ni instalación de dependencias para este MVP.

## Relación con los requerimientos

El MVP implementa principalmente las necesidades identificadas durante la elicitación:

- Registrar movimientos financieros.
- Categorizar gastos.
- Consultar el comportamiento financiero.
- Comparar gastos mensuales.
- Recibir retroalimentación mediante la mascota virtual.
